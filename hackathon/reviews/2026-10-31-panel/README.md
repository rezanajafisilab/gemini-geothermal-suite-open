# Review panel, 31 Oct 2026

Twelve reviewer agents, each in one role, used the running agent through `hackathon/scripts/panel.py`. Each one also read the code and wrote one report here.

The roles: hackathon judge, geothermal specialist, reservoir simulation expert, production engineer, district energy engineer, economist, operator, municipal planner, ML and LLM expert, agentic AI expert, red team, and UI and UX designer.

`panel_guide.md` is the brief they all got. `build_page.py` builds the summary page (verdicts, what was fixed, open items by priority, then every report) from these files. Run it with `python build_page.py`.
